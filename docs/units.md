# Object types

Generated by `scripts/gen_units.py` from the game data - do not edit. Every unit and building type with its id,
its **identifier** and its English name. The identifier is the type's internal name in the game data, the same in
every game language: lowercase, every run of other characters one `_` (`b  Guard Tower - Bronze` ->
`b_guard_tower_bronze`). The prefixes are the designers': `b` building, `a` aircraft, `inf`/`arch`/`cav` + the
epoch infantry, archers, cavalry, `gun` siege and guns, `x` special variants, `amb` animals, `res` resources.

Kind is the game's family of the type (its armour and bonus class). Buildings come first in each epoch.

The stats are the base values from the data, before upgrades and civilization bonuses: hit points, attack,
range and line of sight in tiles, speed, population, cost food/wood/stone/gold/iron and build time in seconds.
Epochs are numbered as in the mod's logs (0 = Prehistoric); "epochs" is from when to when the game offers it.
