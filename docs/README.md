# Documentation

What each page here is for, grouped by who reads it. What the mod is and how to install it:
[README.md](../README.md) at the root; how a change gets merged: [CONTRIBUTING.md](../CONTRIBUTING.md).

## Playing with the mod

- [installing.md](installing.md) - which game versions the mod runs on, installing by hand, the settings window,
  the game's settings in a file, NeoEE, multiplayer, and the status of each part.
- [ai-features.md](ai-features.md) - what the mod changes in the computer player, feature by feature, with the
  `ageofai.ini` keys that switch each one.
- [game-fixes.md](game-fixes.md) - the fixes to the game itself, for every player: window and picture, the scenario
  editor and camera, fights and sight, walls, selection and transports, movement, sound, other DLL mods beside it.
- [diplomacy.md](diplomacy.md) - diplomacy, the personalities and their texts, the AI's voice.
- [units.md](units.md) - every unit and building type by epoch with its id and identifier, the names the scripts
  use (generated by `scripts/re/gen_units.py`: do not edit).

## Writing personalities and scripts

- [config/personalities/README.md](../config/personalities/README.md) - the .eeai text language as the
  personalities use it: records, expressions, situations, the lines the AI says.
- [scripts.md](scripts.md) - the language's scripts: statements, types, structs, refs, functions, triggers, timers,
  `setup.eeai` (every game's script), saved games, the dry run.

## Working on the mod

- [development.md](development.md) - building, setting up the reverse-engineering tools, the tree's layout.
- [testing.md](testing.md) - autotest mode, running tests (the test server, suites, head-to-head, A/B over seeds),
  the log, the control pipe.
- [renderer.md](renderer.md) - the mod's own DirectX 7 on Direct3D 11: what the game calls, the frame and the
  simulation's lock, the units' collection and draw, shadows, fog, water.

## The game as the mod knows it

- [engine-notes.md](engine-notes.md) - the engine's objects, addresses and layouts by topic (players, units, the
  computer player's managers, attacks, data files, saved games, drawing, sound), the exe builds and Art of Conquest.
  The source of truth for addresses is `spec/`; this page explains them.
- [triggers.md](triggers.md) - how the scenario editor's triggers run: the conditions and effects reversed.
- [game-ai-routines.md](game-ai-routines.md) - what the game's own computer player decides, what the mod replaces,
  and the mod's players with it off (`game_ai = 0`, the default since 2026-11-14).

## Research and measurements

- [ai-analysis.md](ai-analysis.md) - how the original computer player works and fails (the cheat hides a broken
  economy), and the first test results.
- [economy.md](economy.md) - the early game against the base game's AI: food, mines, citizens, metal, islands and
  outposts, falling back to cover, each with its measurements.
- [navy.md](navy.md) - the ships' roles from the game's data, the game's AI at sea, a baseline on island maps, the
  design of a standing navy.
- [experiments.md](experiments.md) - the AI-behaviour switches that are off: why each failed and what was missing.
